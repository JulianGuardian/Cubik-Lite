# Base de Conocimiento de Cálculo Integral - Cubik-Lite

Esta carpeta contiene el corpus de conocimiento educativo para **Cubik-Lite**, un asistente y tutor inteligente de cálculo integral diseñado para estudiantes universitarios. Todo el contenido está redactado en español con rigor matemático y notación formal en LaTeX.
